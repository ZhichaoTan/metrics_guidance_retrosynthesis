# Retro* patch provenance

`binghong_retro_star.patch` applies to
[`binghong-ml/retro_star`](https://github.com/binghong-ml/retro_star) commit
`60e7a24213810706a7075d113704c9320158d726`, under the accompanying MIT
license (`BINGHONG_LICENSE`).

The patch adds only the interfaces required here: optional search-depth
semantics, planner-native open-frontier selection, per-target selector reset,
model-call reporting, and best-route return. It is applied by
`scripts/setup_binghong_retro_star.sh`.
